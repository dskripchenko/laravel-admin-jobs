# dskripchenko/laravel-admin-jobs

> 🌐 [English](../../README.md) · [Русский](../ru/README.md) · [Deutsch](../de/README.md) · **中文**

Laravel 队列查看器：failed jobs、batches、队列深度。轻量级，无需仪表板服务器。

[`dskripchenko/laravel-admin`](https://github.com/dskripchenko/laravel-admin) 的姐妹包。

## 安装

```bash
composer require dskripchenko/laravel-admin-jobs
php artisan migrate
```

插件通过 Laravel package discovery 自动注册。
